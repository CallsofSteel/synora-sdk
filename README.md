# Synora SDK Snapshot

> **Status: Upstream-derived archive**

This repository contains an imported snapshot associated with the Synora x402 payment-gateway project. Earlier history and documentation reference the upstream organization and packages rather than an original CallsofSteel implementation.

## Attribution

The SDK design, package names, examples, service endpoints, and original documentation belong to the Synora project and its contributors. This repository is retained for research into x402-based machine payments and is **not** presented as original CallsofSteel work.

The historical documentation referenced:

- Python and JavaScript/TypeScript SDKs
- HTTP 402 payment flows
- USDC settlement on Base
- Synora-hosted APIs and packages

Those services, packages, links, prices, and endpoints may have changed or disappeared. Nothing in this snapshot should be assumed current without independent verification.

## Security warning

Do not place private keys, seed phrases, production credentials, or valuable wallet funds into archived SDK examples. Before using any payment SDK, independently verify:

- Package ownership and release provenance
- Current source repository
- Contract and recipient addresses
- Chain and token configuration
- Transaction signing behavior
- Service availability and terms
